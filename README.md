# ⚽ Web Tabanlı Menajerlik ve Maç Simülatörü

Bu proje, HTML5, CSS3 ve saf JavaScript (ES6+) kullanılarak geliştirilmiş modern bir futbol menajerlik ve canlı maç simülasyon oyunudur.

## 🚀 Özellikler
- **10 Büyük Lig & Takımlar:** Premier League, La Liga, Serie A, Bundesliga, Süper Lig, Ligue 1 ve daha fazlası.
- **Dinamik Oran & Maç Motoru:** Takım güçlerine (OVR) göre gerçekçi iddaa oranları ve Canvas 2D animasyonlu maç simülasyonu.
- **Kariyer Modu:** Lig fikstürü, haftalık puan durumu ve detaylı istatistikler.
- **Transfer Pazarı:** Oyuncu satın alma, bütçe yönetimi ve takım gücünü geliştirme mekanizması.
